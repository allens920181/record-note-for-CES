# 神學院錄音筆記軟體 — 需求規格 v0.1

> 狀態：需求釐清中。本文是討論用的活文件，決定一項就把「待拍板」搬到「已確認」。

---

## 0. 一句話定位

給神學院學生的課堂工具：**錄音 → 逐字稿 → 雙欄筆記 → 整學期知識庫**。
資料存在自己的電腦，AI 用自己的 API key，不經過任何第三方伺服器。

---

## 1. 已確認的決定

| 項目 | 決定 | 影響 |
|---|---|---|
| 平台形式 | 純網頁 local-first | 免安裝、免後端、免月費；資料在自己機器上 |
| 錄音來源 | ① 事後上傳音檔 ② App 內直接錄音 | 兩條路都要做；① 先做，② 工程量較大 |
| 課程串聯 | 全學期總覽 + 跨週搜尋、AI 生成複習包 | 需要全文索引層 + 分層摘要策略 |
| 首版範圍 | 錄音轉錄+雙欄筆記、學期/課程/週次+課表、PDF+閱讀材料、作業規劃 | 四大塊全做，但分階段交付（見 §5） |

## 2. 需要先講清楚的三件事

這三點會直接改變架構，先攤開來講。

### 2.1 「自己輸入 AI API」其實是兩把鑰匙，不是一把

**Anthropic 沒有語音轉錄端點。** 只填 Claude 的 key，錄音是轉不出逐字稿的。所以設定頁必須拆成兩區：

| 用途 | 可選 provider | 備註 |
|---|---|---|
| **STT 語音轉文字** | OpenAI Whisper、Groq、Deepgram、ElevenLabs、Gemini | Claude 不提供此功能 |
| **LLM 文字處理**（摘要、整理、複習包、問答） | Claude、GPT、Gemini | 這裡才是 Claude 的主場 |

兩區各自獨立設定 provider + key + model，各自有「測試連線」按鈕。

### 2.2 純前端直打 API 的 CORS 現實

瀏覽器直接呼叫 API，對方伺服器要允許跨域才行。

- **Anthropic — 已實測可用。** 回應 `access-control-allow-origin: *`，並明確允許 `anthropic-dangerous-direct-browser-access` header。呼叫時要帶這個 header（SDK 則是 `dangerouslyAllowBrowser: true`）。
- **OpenAI / Groq / Gemini — 尚未驗證。** 開發沙盒的網路政策擋住了這幾個網域，無法實測。**這是開工前第一件要在你自己瀏覽器上驗的事**（開 devtools console 打一發就知道，5 秒）。
- **若某家不支援 CORS**：備案是加一層極薄的 proxy（Cloudflare Worker 免費額度綽綽有餘），但那就不是「純前端」了。所以先驗證再決定推薦哪家。

### 2.3 一堂 3 小時的課，檔案比你想的大

神學院的課常是 2–3 小時。這帶出三個必須處理的工程問題：

1. **轉錄 API 有檔案大小上限**（Whisper API 為 25MB）。3 小時錄音就算壓成 opus 64kbps 也約 85MB → **必須切片**：重新編碼成低碼率 → 依靜音點切成數段 → 逐段轉錄 → 時間戳偏移校正後拼接。（用 `ffmpeg.wasm` 在瀏覽器裡做完，不外傳。）
2. **瀏覽器儲存配額不夠**。一學期 4 門課 × 15 週 × 85MB ≈ **5GB**。IndexedDB 配額通常撐不住 → 所以「選一個本機資料夾存檔」（File System Access API）對你不是進階選項，而是**必要功能**。
3. **瀏覽器連續錄 3 小時不穩**。分頁切到背景會被節流、螢幕休眠會斷。對策：每 3–5 分鐘寫一塊到磁碟（當機最多丟 5 分鐘）、Wake Lock API 防休眠、可暫停續錄。

## 3. 資料模型（「切學期 / 每週開新檔 / 整課串聯」的骨架）

```
Term 學期  ── 名稱、起訖日、狀態
 └── Course 課程 ── 課名、教授、學分、課號、代表色
      ├── 上課時段 ── 星期幾 / 幾點 / 教室（可多段）
      ├── Syllabus 教學大綱（PDF）
      ├── Glossary 專有名詞表 ← 見 §4.2
      │
      ├── Session 週次  ← 依課表自動預生成
      │    ├── 第 N 週、日期、主題、是否停課
      │    ├── Recording  錄音（可多段，含分段續錄）
      │    ├── Transcript 逐字稿（帶時間戳，可編輯修正）
      │    ├── Note       我的筆記（Markdown，可插時間戳）
      │    ├── AI Output  摘要 / 大綱 / 自動生成的問題
      │    └── Attachment 當週講義
      │
      ├── Assignment 作業 ── 標題、截止日、狀態、關聯週次
      │    └── SubTask 子任務（作業規劃）
      │
      └── Reading 閱讀材料 ── 書目、頁數範圍、對應週次、進度、讀後筆記
```

三層縱向結構（學期 → 課程 → 週次）解決「切學期」「每週開新檔」；
作業與閱讀材料掛在課程層並可指回週次，解決橫向關聯。

## 4. 逐項功能規格

### 4.1 錄音與轉錄

- **上傳**：mp3 / m4a / wav / webm / mp4，拖放即可
- **內建錄音**：分段落磁碟、Wake Lock 防休眠、暫停/續錄、即時波形與計時
- **轉錄流程**：自動壓縮 → 靜音點切片 → 逐段送 STT → 時間戳校正拼接
- **進度與韌性**：每段獨立進度、單段失敗可重試、不必整份重來
- **成本預估**：送出前先顯示「這份約 X 分鐘，預估 $Y」
- **匯入現成逐字稿**：srt / vtt / txt（老師已提供時省下轉錄費）

### 4.2 專有名詞表 — 神學院的關鍵功能

這是一般錄音軟體不會有、但對你影響最大的功能。神學院課堂充滿：

- 希臘文 / 希伯來文原文與音譯（*logos*、*chesed*、*hesed*）
- 神學家人名（巴特、士來馬赫、加爾文、奧古斯丁、莫特曼）
- 宗派與專業術語（釋經學、預定論、稱義、成聖、位格）

通用 STT 模型幾乎一定會轉錯這些字。解法：**Whisper API 的 `prompt` 參數可以餵詞彙表**，直接大幅提升這些詞的準確度。

設計：每門課一份詞彙表，可手動加、也可從逐字稿的修正紀錄自動累積（你改過一次「加爾聞→加爾文」，之後自動記住）。

### 4.3 雙欄：逐字稿 ↔ 我的筆記

| 左欄：逐字稿 | 右欄：我的筆記 |
|---|---|
| 帶時間戳、跟著音檔捲動 | Markdown 編輯器 |
| 可直接編輯修正錯字 | 可插入時間戳連結 |
| 可 highlight / 標記 | 可引用左欄選取的段落 |
| 全文搜尋定位 | 可貼圖、可連到 PDF 頁碼 |

**最有價值的一件事：筆記裡的時間戳點下去，音檔直接跳到那一秒。**
上課時只要按快捷鍵打個記號（「這裡沒聽懂」），回家點一下就回到那個瞬間。

AI 動作（都是選擇性觸發，不自動燒錢）：整段摘要、抽出大綱、標記重點、生成複習問題、把口語逐字稿整理成通順文章。

### 4.4 課表與自動開檔

- 設定每門課的上課時段（可多段）
- 依「學期起訖 + 課表」**自動預生成整學期 15–18 個週次檔案**
- 可標記停課 / 放假週
- **首頁儀表板**：本週有哪些課、哪幾週還沒錄音、哪幾週沒寫筆記、哪些作業快到期

### 4.5 PDF 與課程檔案

- 上傳 syllabus、講義、閱讀材料，掛在課程層或週次層
- 內建 PDF 檢視器（pdf.js）
- **抽出文字**：讓 PDF 內容可被全文搜尋，也可餵給 AI
  → 「拿這週講義對照逐字稿，老師講到但講義沒寫的重點是什麼？」

### 4.6 作業清單與規劃

- 清單視圖 + 截止日 + 狀態 + 關聯課程／週次
- **子任務拆解**：一份期末報告拆成「選題 / 找文獻 / 大綱 / 初稿 / 修稿」
- 時間軸／行事曆視圖，看見死線擠在一起
- AI 輔助：貼上作業要求 → 自動拆步驟並回推時程

### 4.7 閱讀材料區

- 書目管理（書名、作者、章節、頁數範圍）
- 對應到週次（這週要讀哪幾章）
- 進度追蹤（未讀 / 讀到第幾頁 / 已讀）
- 讀書筆記，可與課堂筆記互相引用

### 4.8 整學期串聯

- **課程時間軸總覽**：一門課 15 週攤開，每週主題、錄音狀態、筆記狀態一目了然
- **跨週全文搜尋**：一次搜尋逐字稿 + 筆記 + PDF 文字，結果顯示「第 8 週 01:23:45」，點下去直接跳到那句話
- **AI 複習包**：整學期總大綱、重點整理、考前題庫、教授反覆強調的主題

**成本策略（重要）**：3 小時中文課約 3.6 萬字 ≈ 5 萬 token，一門課整學期約 75 萬 token。Claude 有 1M context 塞得下，但每跑一次全學期要約 $3.75（Opus 5 輸入 $5/M）。

所以採**分層摘要**：學期中每週轉錄完順手做一份週摘要（約 $0.30，本來就會做）→ 期末只把 15 份摘要（約 3 萬 token）餵進去彙整，**邊際成本降到約 $0.15**。

若要「跟整學期的課對話」反覆問答，則開啟 **prompt caching**：快取讀取只要 0.1 倍價，同一份 75 萬 token 的資料重複問，每次約 $0.375 而非 $3.75。

### 4.9 儲存與備份

| 模式 | 說明 | 適用 |
|---|---|---|
| 瀏覽器內建（OPFS/IndexedDB） | 免設定，開網頁就能用 | 試用、少量資料 |
| **本機資料夾**（File System Access API） | 選一個資料夾，音檔/PDF 直接存你的硬碟，資料庫只存索引 | **你的實際用量必須用這個**（見 §2.3） |

- 一鍵匯出 zip 備份（含 Markdown 檔，可直接餵給 Obsidian）
- 可匯入還原、可換電腦
- 「轉錄完成後自動刪除音檔」選項（省空間，逐字稿留著）
- API key 存本機 IndexedDB，可選用密碼加密（WebCrypto AES-GCM）

> ⚠️ File System Access API 只有 Chrome / Edge 支援，Safari 和 Firefox 沒有。這會限制你的瀏覽器選擇。

## 5. 建議的交付階段

首版四大塊全做 = 下面 Phase 1–3。但**每個 Phase 結束都是能實際拿去上課用的狀態**，不必等全部做完。

| Phase | 內容 | 做完後你能做什麼 |
|---|---|---|
| **1** | 資料模型、學期/課程/週次、上傳音檔轉錄、雙欄筆記、時間戳跳轉、本機資料夾儲存 | 課後上傳錄音，做出可點跳的雙欄筆記 |
| **2** | 內建錄音（分段+Wake Lock）、課表自動開檔、PDF 上傳與檢視 | 帶筆電直接上課錄，整學期檔案自動排好 |
| **3** | 作業清單與規劃、閱讀材料區、跨週全文搜尋 | 學期的所有事情都在同一個地方 |
| **4** | AI 複習包、專有名詞表、匯出 Obsidian、成本儀表板 | 期末一鍵生成複習資料 |

## 6. 待你拍板

| # | 問題 | 為什麼要問 |
|---|---|---|
| 1 | **授課語言？** 純中文？中英夾雜？會出現希臘文/希伯來文原文嗎？ | 決定 STT provider 選擇與詞彙表設計。中英夾雜對某些模型是硬傷 |
| 2 | **實際規模？** 一堂課幾小時、一學期幾門課？ | 直接決定儲存容量與整學期的轉錄花費 |
| 3 | **轉錄預算容忍度？** | Whisper API 約 $0.36/小時。若一學期 180 小時 ≈ $65。Groq 便宜得多但需確認最新價與 CORS |
| 4 | **主要用哪個瀏覽器？** | Chrome/Edge 才有 File System Access API（見 §4.9 警告） |
| 5 | **需要講者分離嗎？** 分辨「教授在講」vs「同學提問」 | 影響 STT provider 選擇（Whisper 不做這個，Deepgram 做） |
| 6 | **錄音要不要加密？** | 課堂若涉及牧養/個人分享，本機加密值得做 |
| 7 | **要不要手機版？** | 目前決定是純網頁 local-first = 資料綁在單一台電腦。手機錄音要另外傳檔 |

## 7. 技術選型（建議，尚未定案）

| 層 | 選擇 | 理由 |
|---|---|---|
| 框架 | Vite + React + TypeScript | 靜態輸出、生態成熟 |
| 資料庫 | Dexie（IndexedDB 封裝） | local-first 標準解 |
| 檔案 | File System Access API + OPFS 備援 | 解決 5GB 容量問題 |
| 音訊處理 | `ffmpeg.wasm` | 壓縮與切片全在瀏覽器完成，不外傳 |
| PDF | `pdf.js` | 檢視 + 抽文字 |
| 編輯器 | TipTap 或 CodeMirror | Markdown + 自訂時間戳節點 |
| 全文搜尋 | MiniSearch 或 SQLite WASM (FTS5) | 跨週搜尋 |
| 部署 | GitHub Pages 靜態站 | 零成本、零維運 |

# record-note-for-CES

給神學院學生的課堂錄音筆記軟體。

**錄音 → 逐字稿 → 雙欄筆記 → 整學期知識庫**
資料存在自己的電腦，轉錄用自己的 API key，不經過第三方伺服器。
摘要與整理由你自己做——軟體只負責讓你找得到、跳得回去、寫得順。

## 現況

需求釐清階段。規格見 [`docs/REQUIREMENTS.md`](docs/REQUIREMENTS.md)。

## 核心構想

- **純網頁 local-first** — 免安裝、免後端、免月費
- **自帶 API key** — 只需一把：語音轉錄。沒有任何 LLM 呼叫
- **學期 → 課程 → 週次** 三層結構，依課表自動開檔
- **雙欄對照** — 左逐字稿、右筆記，時間戳點下去音檔直接跳轉
- **整學期串聯** — 跨週全文搜尋，純本地檢索
- **神學院專用詞彙表** — 讓 STT 認得神學術語與原文音譯

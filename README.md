# record-note-for-CES

給神學院學生的課堂錄音筆記軟體。

**錄音 → 逐字稿 → 雙欄筆記 → 整學期知識庫**
資料存在自己的電腦，轉錄用自己的 API key，不經過第三方伺服器。
摘要與整理由你自己做——軟體只負責讓你找得到、跳得回去、寫得順。

## 現況：Phase 5 · 功能齊備，並做過一輪化繁為簡

規格見 [`docs/REQUIREMENTS.md`](docs/REQUIREMENTS.md)。

**外殼**

- **左側側邊欄**：五個功能頁（行事曆／作業／搜尋／詞彙表／設定）在上，
  下面是這學期的課程樹——點課名進課程頁，展開就看到每一週，點週次直接進工作區。
  你正在看的那門課會自己展開並標起來，停課的週次是灰的
- **每門課各自收合**：課名前面那顆 ▸ 只管自己那幾週，開一門不會關掉另一門。
  要對著兩門課工作就把兩門都打開，不看的那幾門收起來。
  **哪幾門開著按學期記住**，關掉瀏覽器再回來還是同一個樣子；
  開超過一門時課程樹右上角出現一個「收合全部」，長了就一下收乾淨
- **沒展開的課不去查資料庫**：一學期五門課是七十幾個週次，
  預先撈起來只為了顯示可能不會被打開的清單
- **收得起來**：`☰` 開關，記住你的選擇。窄視窗下改成蓋在頁面上，
  點連結或點旁邊就收起來——寬視窗不會，那裡它是家具的一部分
- **進工作區時自己收起來**，離開再回來：那裡是兩欄你自己寫的東西，
  旁邊 15rem 的課程樹不會有人在看。但只收自己收的那次——
  在工作區裡自己把它拉開，離開時就讓它開著
- **頂端只剩麵包屑**。原本五個導覽連結和麵包屑擠在同一行，路徑一長就換行

**Phase 1 — 錄音轉錄與雙欄筆記**

- 學期 → 課程 → 週次三層結構。**學期長度就是開始日到結束日**，
  週數是算出來的一句話而不是另一個要你填、還會跟日期打架的欄位
- **課程可以標必修／選修**（也可以不標——沒說過和選修不是同一件事）。
  學期抬頭會把兩邊的學分各自加起來，只算你真的標過的那幾門
- 選一個本機資料夾存音檔（Chrome / Edge），沒有的話退回瀏覽器內建空間
- 上傳音檔 → 壓成 opus → 切片 → 逐段轉錄 → 拼回完整逐字稿
- **逐字稿一定是繁體中文**。Whisper 認得中文，但預設寫简体——
  `language: 'zh'` 只說語言不說字體。所以送出去的提示先用繁體寫一句給它看，
  收回來的每一段再過一次 OpenCC 的 s2tw；轉換看得懂詞，
  所以「头发」是頭髮而「发展」是發展。舊的逐字稿在「⋯ → 轉成繁體中文」可以就地改寫，
  不必再送一次 API
- 雙欄工作區：左逐字稿、右 Markdown 筆記
- **時間戳跳轉**：點逐字稿任一句、或點筆記裡的 `[[hh:mm:ss]]`，音檔跳到那一秒
- `Alt+T` 把目前播放時間插進筆記
- 逐字稿可就地修正錯字，筆記自動存檔
- **0.75×–2× 播放**，而且保持音高。速度記在設定裡——會用 1.5× 聽課的人每一週都用 1.5×
- **一堂課可以有好幾段錄音**：中場休息、手機沒電重錄、分兩天補課。
  **每段各自從 0:00 起算**，不接成一條假的時間軸；逐字稿上方切換段落，
  筆記裡的時間戳寫成 `[[第2段 00:12:30]]`，點下去會自己切到那一段。
  重新轉錄、換音檔、刪除都只動你正在看的那一段
- **標記誰在講話**：轉錄服務不會分辨說話者（OpenAI 相容的 API 沒有這個輸出），
  所以做成便宜的手工——只標「換人講」的那一句，往下沿用；
  停頓超過 1.5 秒的地方先幫你標出來，三小時的課點幾下就好。
  名字記在課上，可以「只看某個人講的」，匯出時會變成 `**老師：**` 開頭

**課程頁：一門課就是一列 block**

- **整頁就是每一堂課的清單**，一堂一個 block。整張卡都是連結，點進去就是那一週的筆記——
  不必先找到標題再點
- **block 之間插得了筆記區**：兩張卡中間有一條線，`＋` 可以放進分組討論、作業紀錄、
  或其他筆記。插在哪就落在哪，不會被丟到最後
- **筆記區不是聚會**：沒有上課時間，也不會跑到行事曆上——那裡只放真的會在某個鐘點發生的事
- **右邊三顆對話框**：編輯課程（含課表與專有名詞表）、課程規定與作業（要求／作業／
  閱讀）、文件總覽。描述「這門課」的東西收在這三顆裡，
  頁面本身維持是那列 block

**筆記區**

- **輸入 `/` 叫出指令選單**：標題、清單、待辦、引用、分隔線、標記、插入時間戳、
  引用逐字稿、**加檔案**。可以打中文篩選，不必記得 markdown 的符號
  （中文輸入法下為了兩個 `*` 切換一次輸入法，是件很煩的事）
- **選取文字就浮出工具列**：粗體、斜體、**底線**、**刪除線**、行內代碼、
  **字色與螢光筆**（各五色／四色），以及三種標記。
  規則是「工具列管字，`/` 選單管段落」
- **底線與顏色寫成 inline HTML**（`<u>`、`<span style="color:…">`、`<mark style="background:…">`），
  因為 markdown 沒有這些語法。存的是 hex，Obsidian 那邊看得懂；
  但在編輯器裡會對映成這個 app 的五個顏色，而不是各自畫各自的 hex
- **快捷鍵印在指令旁邊**：`Ctrl+B` / `Ctrl+I` / `Ctrl+1~3` / `Alt+↑↓`（搬動整段）
  / `Alt+T`（插入時間戳）。按你這台電腦的鍵盤顯示——Mac 上是 `⌘⌥`，
  Windows 上就寫 `Ctrl`／`Alt`
- **markdown 當場就畫出來**：標題是大的、粗體是粗的、引用有左邊框、
  待辦是可以點的框。游標所在的那一行會把符號顯示出來讓你改，離開就收起來
- **標記 重點 / 疑問 / 考點**：用 Obsidian 的 callout 語法（`> [!疑問] …`）存，
  在編輯器裡是有顏色的區塊，匯出到 Obsidian vault 那邊也認得
- **引用逐字稿**：在左邊選一段話，一鍵成為筆記裡的引用，**帶著那句話自己的時間戳**——
  不是目前播放時間。點下去跳回原音
- **大綱**：標題與標記自動組成跳轉清單，長筆記不必捲。目前寫到哪一節會標出來
- **整學期回顧標記**：搜尋頁上開「疑問」，所有課所有週標過的疑問一次列出來，考前複習用
- **不只週次筆記能用**：課堂要求、作業的要求與備註、讀書筆記都換成同一個編輯器——
  一樣的 `/`、一樣的快捷鍵、一樣的標記。那些欄位裡沒有音檔也沒有逐字稿，
  所以時間戳、引用逐字稿、加檔案會自己從選單裡消失。逐字稿的修正框**不**換，
  那裡的內容不是 markdown

**Phase 2 — 帶去教室**

- **App 內直接錄音**：每 3 分鐘把一段寫進你的資料夾，分頁當掉最多丟 3 分鐘；
  可暫停續錄、有音量表與計時，並請求螢幕保持喚醒
- **中斷復原**：上次沒錄完的片段留在磁碟上，回到該週次就能復原並轉錄
- **課表自動開檔**：課表只放**每週固定**的正課與分組討論，各自每週開一個檔案
  （兩場是分開的錄音，時間軸無法合併），同一週共用同一個週次編號。
  一鍵產生整學期，重複執行不會產生重複
- **日期一律是你這裡的日期**：產生日期時曾經先換算成 UTC 才寫下來，
  而台灣的午夜在 UTC 還是前一天——設週二，開出來整學期都是週一，
  而且第一堂落在開學日之前，害它和第二堂並列「第 1 週」。
  現在日期只用本地時間算。已經開歪的那些，課程頁上會出現一則提示，
  按一下就把**時間與類型仍然對得上課表**的那幾堂移回正確的那一天並重新編號；
  自己改過日期的、補的課不會被碰到
- **單次聚會**：只開一次的分組討論或補課，直接指定日期新增，不必寫進課表
- **檔案哪裡加都行，一個地方看得完**：課程層傳教學大綱、週次層傳當週講義，
  或在筆記裡打 `/檔案` 直接加。三種來源都是同一批資料，
  「文件總覽」一次列完並標出每份屬於哪一週。PDF 會抽出文字備跨週搜尋用
- **專有名詞表**：每門課一份，一個詞一顆，隨轉錄一起送出；也可在逐字稿選取文字直接加入
- **每一列的其他動作收在「⋯」裡**：標記停課、刪除。
  一學期是三十列，把「刪除」擺在每一列上等於給最危險的動作最穩定的位置

**行事曆**

- **週曆**：7 天 × 時間格，衝堂的課會並排顯示而不是互相蓋住；課程用代表色區分
- **月曆**：一眼看完整學期的節奏
- **點空白處就建立**：選課程、類型（正課／分組討論）、重複（每週／單次）。
  週曆依點擊位置預填時間並對齊半小時；月曆沒有時間格可點，就問這門課平常怎麼上
- 每週的會寫進課表並展開整學期；單次的只建一個週次
- **點既有項目會開一張卡片**：這是什麼、帶我去（那一週的工作區／那份作業／課程設定）、
  改時間、標記停課、從行事曆拿掉
- **每個對話框標題列都有 ✕**：長對話框的「關閉」在三個螢幕以下，而人是往上找的
- 一天超過三件事時，月曆的「還有 N 項」按得下去，會切到那一天的週曆
- 學期還沒開始時，日曆會停在學期第一週而不是空白的今天

**Phase 3 — 學期全景**

- **作業規劃**：跨課程依截止日排序，可拆解步驟並套用範本（期末報告／讀書報告／講道稿）
- **三種看法，同一批作業**。選了哪一種會記起來，下次進來還是那一種
  - **清單**依截止日排，回答「下一個要交的是什麼」
  - **看板**依狀態分成未開始／進行中／已完成三欄，回答「我手上正在做的是哪幾份」——
    這件事清單答不了，因為截止日不會說一份報告有沒有動工。
    卡片用箭頭換一欄，桌機也可以直接拖；日期照樣印在每張卡片上
  - **畫廊**一門課一區，回答「這門課欠了什麼」——坐在那門課裡的時候問的就是這個。
    磁磚上寫著截止日與**下一步**（第一個還沒打勾的步驟）。
    沒有作業的課也有自己的一區：空的架子就是答案，而那裡也是放第一件東西的地方
- **還要多久**：拆解步驟並填上預估時數，卡片上就寫著還要幾小時——
  「還有 21 天」和「還要 9 小時」是兩件事，後者才是能不能寫完的關鍵
- **截止日出現在行事曆**上，週曆與月曆都看得到
- **跨週全文搜尋**：一次搜尋所有逐字稿、筆記與 PDF 文字。
  中文沒有空白，所以用子字串比對而非詞元索引——搜你記得的那句話就找得到。
  點搜尋結果會直接跳到音檔的那一秒
- **閱讀材料**：書目、章節、頁數進度、對應週次、讀書筆記

**Phase 4 — 越用越準、拿得走**

- **詞彙表總表**：頂端「詞彙表」進去，一頁看完所有課程的專有名詞。
  轉錄時送給模型的是**全域詞彙 ＋ 那門課自己的詞彙**，所以同一個詞不必兩邊都放。
  在兩門以上出現的詞會被挑出來建議升成全域；也可以一鍵改名（所有課程一起改）、
  複製到別門課、或整個刪掉
- **詞彙表自動累積**：你在逐字稿上改過的字都會被記下來。
  英文與原文音譯（chesed、Barth）改**兩次**以上會自動進詞彙表；
  中文沒有詞界可循，所以只列出幾個候選讓你點一下決定——
  猜錯會教模型寫錯字，比不猜更糟。純標點的修改不算數
- **匯出 Markdown**：一個學期寫成 `學期/課程/第 N 週.md` 的資料夾樹，
  帶 YAML front matter、你的筆記、以及每行前綴 `` `[hh:mm:ss]` `` 的逐字稿。
  指向 Obsidian vault，筆記就直接在那裡了
- **備份與還原**：一個 JSON 檔含全部結構、逐字稿、筆記與**全域詞彙**。
  音檔本來就在你選的資料夾裡，那就是它自己的備份，不重複打包；
  API key 與用量屬於這台機器，不進備份
- **用量儀表板**：對照 Groq 免費層的每日 8 小時與每小時 2 小時，滾動視窗計算。
  轉錄前如果這份錄音會超過今天剩下的量，程式會先問你

**Phase 5 — 這門課要我做什麼、我做到哪**

- **課堂要求**：一個文字框，把大綱裡的評分方式與規定抄進去就好——
  「期末報告 40%、報告 8–10 頁芝加哥格式、遲交每日扣 5 分」這種**寫作業寫到一半會想查**的事。
  查的是一句話，不是一張表，所以不做欄位。下方就是**書目上傳區**：
  教學大綱、指定書目、整學期共用的閱讀材料都傳這裡，PDF 會抽出文字讓跨週搜尋找得到
- **每週學習進度**：每一週排你打算為這門課做的事，可填預估時數、可勾選。
  和作業的步驟不同——那是為了一份有截止日的東西，這裡是這一週本身：
  課前讀完、課後整理、報告再往前推一段。三個範本（一般週／報告週／考前週）可直接套
- **指定閱讀一鍵拉進本週進度**，勾完會同時把那本書在閱讀清單標成已讀完
- **整學期進度**：課程頁最上面是總計，每一週的清單各自帶自己的進度
  （`進度 3 / 5 · 還要 3h`）與狀態色。**沒排進度的週次不算落後**，只是還沒想過
- **「課程規定與作業」列出這門課自己的作業**，和作業頁是同一張卡片、同樣的操作
- **閱讀材料可以直接上傳電子檔**：在那一本書底下傳 PDF，之後在閱讀清單就能讀；
  同一份掃描檔可以給好幾筆閱讀共用，不必重傳

## 一次化繁為簡

功能齊備之後做了一輪整理，原則是：能通用的就整合，但不為了少而少。

- **同一件事只有一種問法**：在課底下排一堂課（正課／分組討論，每週或單次）
  只剩一個對話框，行事曆與課程頁共用；六顆「新增…」按鈕收成三顆
- **同一件事只有一種樣子**：作業的拆解步驟與每週進度是同一種清單；
  「做完幾項」四處同一個寫法；十處 `window.confirm` 收成一種確認對話框
- **打字不會被吃掉**：文字與數字欄位離開才存（按 Escape 還原），
  不再每打一個字寫一次資料庫
- **每個空狀態都有出路**，按鈕不能失效卻不說原因；打開的對話框進網址，
  重新整理與上一頁都回得到原處；打錯的網址會看到真的 404
- **名字要說得出它是什麼**：課程頁上曾經是「課表 · 作業時間 · 詞彙表」這種名詞清單。
  需要三行免責聲明的名字就是錯的名字（「作業時間」曾經是這樣的一個，
  後來整個拿掉了——見下）
- **說明只在需要的時候出現**：卡片空著才解釋它是幹嘛的，有內容之後就讓位。
  四段一樣長的灰字等於沒有輕重
- **空的卡片不出現**：還沒有修正紀錄時，那張卡整個不在；
  一堂課都還沒有時也不顯示「學習進度」——下面的空狀態已經說了同一件事
- **課表併進「編輯課程」**：上課時間就是「這門課是什麼」的一部分，
  標題列本來就把它印在學分旁邊。建課的時候一起說完，不必建完再去別的分頁排一次
- **一列上放什麼，看一學期會按幾次**：「刪除」和「標記停課」不再掛在三十列的每一列上，
  收進一顆「⋯」；數上課的地方說「堂」不說「週」
  （一週可能有正課也有分組討論）
- **拿掉「寫作業的時段」**：它是一段不產生任何東西的時間，存在的唯一理由
  是替作業規劃算出「截止日前還剩幾小時」。那個數字要靠整學期維護那張表才誠實，
  而過期的數字比沒有更糟。現在行事曆上排的都是**真的會發生的事**，
  作業卡片只講截止日與剩下的步驟

## 開始使用

這是網頁 app，**沒有安裝檔**。把 `dist` 下載下來直接點 `index.html` 只會得到白畫面——
瀏覽器不允許 `file://` 載入 ES 模組。它需要一個 server 端著，不管是你電腦上的還是雲端的。

### 方式一：部署到 Netlify（設定一次，之後開網址就好）

repo 裡的 `netlify.toml` 已經寫好建置指令與發佈目錄，Netlify 會自己讀，不必手動填。

1. 到 [netlify.com](https://app.netlify.com) 用 GitHub 帳號登入
2. **Add new site → Import an existing project → GitHub**，選 `record-note-for-CES`
3. 建置設定會自動帶出（`npm run build` / `dist` / Node 22），按 **Deploy**
4. 兩三分鐘後會拿到一個 `xxx.netlify.app` 的網址，可以在 Site settings 改成好記的名字

之後每次推上 GitHub，Netlify 會自動重新建置。網址是 HTTPS，
[App 內錄音需要的就是這個](#需要知道的事)。

### 方式二：在自己電腦跑

```bash
npm install     # 會自動把 ffmpeg core 複製到 public/
npm run dev     # 然後開 http://localhost:5173
```

需要 Node.js 20.19+ 或 22.12+（Vite 7 的要求）。每次使用都要讓這個指令開著。

> **兩種方式的資料是分開的。**
> 你的課程、逐字稿與筆記存在**那個瀏覽器**的 IndexedDB 裡，音檔存在你指定的本機資料夾。
> `localhost:5173` 和 `xxx.netlify.app` 是兩個不同的來源，各自有各自的資料庫。
> 挑一個用到底；真要搬家就用「設定 → 匯出與備份」的備份檔。

首次開啟請到「設定」完成兩件事：

1. **選擇本機資料夾** — 音檔存這裡。一學期約需 4.5 GB，瀏覽器內建空間的配額通常不夠。
2. **填入轉錄 API key** — 預設走 Groq 的 `whisper-large-v3`。
   到 [console.groq.com](https://console.groq.com) 申請即可，免費層每日 8 小時音訊。

按「測試連線」確認金鑰可用，再回到週次頁面上傳錄音。

## 需要知道的事

- **瀏覽器**：本機資料夾用的是 File System Access API，只有 Chrome 與 Edge 支援。
- **首次轉錄會下載約 32 MB** 的 ffmpeg 音訊處理引擎，之後就不用再下載。
- **繁體字表另外下載約 0.5 MB**（第一次轉錄中文時），之後也不用再下載。
  萬一下載不到，逐字稿照樣存起來——只是可能留著简体，之後再轉即可。
- **轉錄期間請保持分頁開著**。關掉的話任務會中斷，需要重新上傳。
- **切片邊界**：音訊每 10 分鐘切一段，跨越切點的字偶爾會被截斷。
  三小時的課大約十幾個切點，影響有限。
- **App 內錄音需要 HTTPS 或 localhost**（瀏覽器對麥克風的要求），Netlify 給的網址符合。
- **`pdfjs-dist` 釘在 5.4.x**：5.5 之後會用到 `Map.prototype.getOrInsertComputed`，
  現行 Chromium 還沒有，升版會讓 PDF 顯示空白頁而且不報錯。
- **速率**：Groq 免費層每分鐘 20 次請求、每小時 2 小時音訊，
  所以一堂三小時的課約需 1.5 小時跑完。程式會自動排隊與重試。

## 技術選型

Vite + React + TypeScript · Dexie（IndexedDB）· File System Access API ·
ffmpeg.wasm（單執行緒，不需 COOP/COEP）· CodeMirror 6（含 markdown 即時樣式與 `/` 指令）· HashRouter ·
pdf.js · 匯出用 File System Access API 寫進你指定的資料夾

純靜態站，沒有後端。部署到 Netlify、Cloudflare Pages、GitHub Pages 都可以——
`base: './'` 加上 HashRouter，代表它在根目錄或子路徑底下都能跑，也不需要任何 server 端的重寫規則。
